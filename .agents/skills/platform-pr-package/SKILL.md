# 平台合并请求整理

将最终差异与真实验证证据整理为简洁的审查交接材料。

## 必需输出

- 按约定式提交格式拟定标题，并明确具体模块或工具范围。
- 说明问题与结果、受影响模块、重要设计决策、兼容性影响和配置影响。
- 契约发生变化时提供接口请求与响应示例；本地拓扑发生变化时说明容器编排或部署影响。
- 列出实际执行的测试与检查、对应结果，以及因外部条件受阻的检查。
- 按需说明安全性、租户隔离、迁移、发布、监控、回滚和剩余风险。
- 提供审查者检查清单，重点覆盖风险最高的调用链。

整理前检查完整差异，排查无关文件、无意义的生成内容变动、凭据、调试输出、过期文档和缺失测试。所有结论必须与命令记录一致；不得把计划中的工作写成已经完成。

此技能只负责准备交接内容。未经明确授权，不得提交、推送、创建、合并或部署合并请求。
