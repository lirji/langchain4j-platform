# 平台差异审查

审查实际差异及其可达调用链。发现项必须是缺陷或实质性风险，而不是风格偏好。

## 审查优先级

1. 租户与部门隔离、身份认证、权限校验、密钥处理、服务端请求伪造、命令执行以及鉴权失败时放行等行为。
2. 跨服务数据传输对象的兼容性、配置默认值、功能开关分支、数据库迁移、事务、幂等性以及事务发件箱语义。
3. 并发、资源清理、重试、超时、资源边界、可观测性以及回滚能力。
4. 变更行为缺少测试，以及文档描述与实际行为不一致。

每个发现项都要给出严重程度、具体失败场景、仓库相对路径形式的 `file:line` 证据，以及边界清晰的修复建议。确认问题前必须复现或追踪对应场景。记录已排除的重要疑点及其排除依据。

除非用户要求修复，否则不要修改文件。没有实际完成独立审查或构建验证时，不得声称已经完成或已经通过。
