# 知识库文档支持范围

核对日期：2026-10-19；源码基线：`d135d6c`。用户主要资料为 PDF、Word、Markdown、Excel、CSV 和技术文档。本文是格式能力清单；实施进度统一见 [PROGRESS_STATE](../delivery/knowledge-parsing-hardening/PROGRESS_STATE.md)，后续工作见[生产优化方案](知识库文档解析生产优化.md#下一阶段优先级)。

## 支持口径

- **样本验证**：已通过仓库中的小型格式样本或分块回归，不能推导为该格式所有变体、版面均正确。
- **解析器已注册**：当前项目依赖中的 Tika 声明支持该格式，上传后可走自动识别和提取；还没有本项目对应真实样本的专项验收。
- **专项待建设**：OCR、复杂版面、结构化定位等能力不能仅根据解析器注册或结果非空宣称完成。

文件文本提取走 [DocumentTextExtractor](../../knowledge-service/src/main/java/com/lrj/platform/knowledge/lifecycle/DocumentTextExtractor.java)。入口没有只允许下表后缀的业务白名单，解析器按内容识别，文件名主要用于展示和日志；下表列的是已核对的常用范围，不是全部 MIME 类型清单。

## 已核对格式

| 文档类型 | 常见扩展名 | 当前证据 | 已验证内容与限制 |
| --- | --- | --- | --- |
| 原生文本 PDF | `.pdf` | 样本验证 | 小型英文原生 PDF 正文；加密和损坏 PDF 的安全错误分类。未验证复杂多栏、跨页表格、中文字体变体或页级覆盖 |
| Word OOXML | `.docx` | 样本验证 | 中文段落及表格文字可抽取；不代表保留单元格关系、标题样式、修订和批注语义 |
| 旧版 Word | `.doc` | 解析器已注册 | 未做真实 DOC 专项样本验证 |
| Markdown | `.md` | 样本验证 | 文本抽取；Markdown 分块策略覆盖 ATX/Setext、标题层级、代码围栏、缩进代码、HTML 注释及原文空白 |
| Excel OOXML | `.xlsx` | 样本验证 | 表头、中文、数值和以字符串存储的前导零；未验证公式缓存、合并单元格、日期或外部链接 |
| 旧版 Excel | `.xls` | 解析器已注册 | 未做真实 XLS 专项样本验证 |
| CSV | `.csv` | 样本验证 | UTF-8 中文和带引号字段的关键内容提取；未验证所有编码、分隔符及字段结构无损还原 |
| 纯文本 | `.txt` | 样本验证 | UTF-8 文本、空正文及输出限额；其他编码仍需专项样本 |
| PowerPoint | `.ppt`、`.pptx` | 解析器已注册 | 未验证幻灯片正文、备注、图表及页级顺序 |
| HTML | `.html`、`.htm` | 解析器已注册 | 未验证复杂页面、正文去噪或动态内容；上传 HTML 文件不等于执行网页 JavaScript |
| 富文本 | `.rtf` | 解析器已注册 | 未做真实 RTF 专项样本验证 |
| OpenDocument 文本 | `.odt` | 解析器已注册 | 未做真实 ODT 专项样本验证 |

“技术文档”是内容类别，会按实际的 Markdown、Word、PDF 等格式处理。当前 [DocumentSplitterFactory](../../knowledge-service/src/main/java/com/lrj/platform/knowledge/DocumentSplitterFactory.java) 由 `app.rag.chunking.strategy` 选择策略，代码缺省为 `recursive`；上传 `.md` 不代表自动启用 `markdown-header`，当前尚无按格式自动选择专用切分策略的完整链路。

## 当前处理边界

1. 输出仍主要是纯文本，再进行分块、embedding 和索引写入。正文能包含表格里的文字，不等于保留行列关系、页码、坐标或引用位置。
2. 扫描/混合 PDF 的 OCR 可用性与质量尚未专项验证，选择性 OCR 和页级完整性检查待建设。不能把只抽出页眉视为整份文件成功覆盖。
3. 旧同步上传另有图片多模态检索分支，默认关闭，开启依赖配置和模型端点；它不等于文档 OCR，也不是异步文档提取链路已完成同等能力的证据。
4. 文件抽取正文默认最多 2,000,000 字符，超限整份失败；空白、加密、损坏和原文读取故障有不同错误分类。输入、配置与发布约束见[可靠入库接入](可靠入库接入.md#文档解析预算与错误分类2026-10-19)。
