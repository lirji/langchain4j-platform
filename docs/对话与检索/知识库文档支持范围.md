# 知识库文档支持范围

核对日期：2026-10-19；基线与进度：KDP-01～04 已交付，KDP-06-A 扩充 17 个场景并修复 CSV 依赖冲突，KDP-05-A 独立进程解析已交付，KDP-06-B 结构化解析/切分及来源传递已通过本地验证。用户主要资料为 PDF、Word、Markdown、Excel、CSV 和技术文档。本文是格式能力清单；实施进度统一见 [PROGRESS_STATE](../delivery/knowledge-parsing-hardening/PROGRESS_STATE.md)，后续工作见[生产优化方案](知识库文档解析生产优化.md#下一阶段优先级)。

## 支持口径

- **样本验证**：已通过仓库中的小型格式样本或分块回归，不能推导为该格式所有变体、版面均正确。
- **解析器已注册**：当前项目依赖中的 Tika 声明支持该格式，上传后可走自动识别和提取；还没有本项目对应真实样本的专项验收。
- **专项待建设**：OCR、复杂版面、结构化定位等能力不能仅根据解析器注册或结果非空宣称完成。

文件文本提取走 [DocumentTextExtractor](../../knowledge-service/src/main/java/com/lrj/platform/knowledge/lifecycle/DocumentTextExtractor.java)。入口没有只允许下表后缀的业务白名单，二进制按内容识别；CSV/Markdown 的文本内容可能无法单独判别格式，已知后缀用于消歧；下表列的是已核对的常用范围，不是全部 MIME 类型清单。

## 已核对格式

| 文档类型 | 常见扩展名 | 当前证据 | 已验证内容与限制 |
| --- | --- | --- | --- |
| 原生文本 PDF | `.pdf` | 样本验证 | 2/30 页英文原生 PDF、页码定位；混合样本的无文本页告警；加密和损坏安全分类。未验证复杂多栏、跨页表格或中文字体变体，OCR 待建设 |
| Word OOXML | `.docx` | 样本验证 | 中文/200 段长文、Heading 与自定义大纲级别、段落/表格顺序、行组携表头及定位；列表编号/修订/辅助内容有保守告警，不承诺完整语义还原 |
| 旧版 Word | `.doc` | 解析器已注册 | 未做真实 DOC 专项样本验证 |
| Markdown | `.md` | 样本验证 | 自动识别 Markdown 结构、源行号、ATX/Setext/层级；代码围栏内标题不切章，短代码整块、长代码保留原始字符分段 |
| Excel OOXML | `.xlsx` | 样本验证 | 双工作表、100 行、表头随行组、空列、中文和前导零；公式读缓存不执行，有缓存未重算、隐藏行和合并单元格告警；不声称展开复杂合并表头 |
| 旧版 Excel | `.xls` | 解析器已注册 | 未做真实 XLS 专项样本验证 |
| CSV | `.csv` | 样本验证 | UTF-8/BOM、中文、引号逗号/换行、空列/前导零、100 行带表头与逻辑行号；宽/长行分组分片。非逗号分隔与任意编码尚未专项验收 |
| 纯文本 | `.txt` | 样本验证 | UTF-8 文本、空正文及输出限额；其他编码仍需专项样本 |
| PowerPoint | `.ppt`、`.pptx` | 解析器已注册 | 未验证幻灯片正文、备注、图表及页级顺序 |
| HTML | `.html`、`.htm` | 解析器已注册 | 未验证复杂页面、正文去噪或动态内容；上传 HTML 文件不等于执行网页 JavaScript |
| 富文本 | `.rtf` | 解析器已注册 | 未做真实 RTF 专项样本验证 |
| OpenDocument 文本 | `.odt` | 解析器已注册 | 未做真实 ODT 专项样本验证 |

“技术文档”是内容类别，会按实际的 Markdown、Word、PDF 等格式处理。文件入口先执行格式结构切分；[DocumentSplitterFactory](../../knowledge-service/src/main/java/com/lrj/platform/knowledge/DocumentSplitterFactory.java) 的 `app.rag.chunking.strategy` 继续用于普通结构块内部，缺省 `recursive`。表格和代码采用专用预算规则；旧 JSON 纯文本入口仍沿用显式策略。

## 当前处理边界

1. 文件入口输出有界结构 JSON，再分块、embedding 与索引；主要格式的页/表/行/段落/章节位置进入最终 metadata、准备快照与检索来源。没有 PDF bbox 或任意复杂版面还原保证。
2. 混合 PDF 已有无文本页告警；选择性 OCR、仅有页眉的低覆盖页和 OCR 质量仍待专项建设，不能将少量文字视为整页内容完整。
3. 旧同步上传另有图片多模态检索分支，默认关闭，开启依赖配置和模型端点；它不等于文档 OCR，也不是异步文档提取链路已完成同等能力的证据。
4. 文件解析应用默认独立 JVM，含输入/正文/页数/临时盘预算和硬执行截止；17 场景 fork 与四类格式受限 Linux 容器验证通过。fork 不是文件/网络安全沙箱，OCR 与递归附件默认关闭。文件抽取正文默认最多 2,000,000 字符，超限整份失败；空白、加密、损坏和原文读取故障有不同错误分类。输入、配置与发布约束见[可靠入库接入](可靠入库接入.md#文档解析预算与错误分类2026-10-19)。
