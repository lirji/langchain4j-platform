# 治理控制台接入

沿用 Vue3/现有会话 store/authorizedFetch，不引入新路由壳层或组件库。
M4：在 ChatToolsPanel 长期画像区内嵌 MemoryGovernancePanel，点击管理才请求真实治理接口。候选确认/拒绝、修改（行内表单）、固定、遗忘（二次行内确认）、停用和审计；409保留输入并提示刷新。身份、凭证和会话变化清空状态，取消旧请求防串用户。
K5：在已有RAG工作台内增加运营区，反馈/候选详情和操作绑定K1-K4实际契约，不硬编码业务数据。桌面和窄屏均采用可换行操作与纵向详情。
测试：组件交互、接口错误、身份切换旧响应丢弃、类型检查和构建；可用浏览器环境下检查截图和真实操作。数据来自API或测试fixture，不在页面硬编码演示数据。
