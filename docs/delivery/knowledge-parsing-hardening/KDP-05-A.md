# KDP-05-A：解析进程与资源边界

用户已授权依优先级实施，并选择普通企业场景；从 `f5c64e1` 的 17 场景基线继续。实现与本地验证已通过，交付状态以 [PROGRESS_STATE](PROGRESS_STATE.md) 为准。

## 行为与边界

1. 文件解析从服务 JVM 移到每次调用独立的 Java 子进程。保留 `DocumentTextExtractor` 调用契约，Spring 的应用配置启用 forked 模式；无参离线测试保持明确的 in-process 基线。生产 worker/combined 不允许静默退回进程内解析。
2. 使用当前固定 artifact/类路径启动专用 main，不启动 Spring、不传服务凭据、不经 shell 拼接命令。Boot fat jar 和 Maven 类路径分别验证；子进程环境采用最小允许列表，不继承 API token/数据库配置或 JAVA_TOOL_OPTIONS。
3. 输入先流式写私有临时目录，缺省字节上限 50 MiB；正文仍是 2,000,000 字符。解析阶段缺省 120 秒硬截止，计时独立于任务租约/心跳。子进程缺省堆 256 MiB、metaspace 128 MiB、direct memory 64 MiB；并发子进程缺省 2，满载明确拒绝/退避，不创建无界排队。
4. 超时、取消、输出超限或临时文件监测超限时终止进程及可见后代，并等待确认退出；没有退出不能释放并发额度或宣称解析停止。错误不包含正文、输入路径或底层 stderr。停止等待不是完成终止。
5. 每次工作目录独立、只在退出后清理本任务文件；磁盘使用和文件数有监测上限。部署容器用 tmpfs 大小和容器 memory/pids/CPU 上限提供进程级之外的硬边界。监测可能短暂超调，JVM `-Xmx` 不是总 RSS 上限；fork 不是 RCE/网络安全沙箱。生产环境须继续使用独立 worker 与受限容器。
6. 页数上限与嵌入对象策略在 Tika 上下文/事件层落实；默认不开启自动 OCR 或递归附件处理，避免库因环境存在外部程序而悄悄扩大成本。页级图片缺文/跳过附件的可见告警由后续结构化结果携带。
7. 原文网络读取受 S3 连接/读取超时限制，不能把普通 Java InputStream 的阻塞读取宣传为可强杀操作。输入暂存和解析执行的预算/监测分别说明，流式上传及全链路批量预算继续由 KDP-05-B 完成。

## 验收

- 六类主格式通过独立子进程，正文与错误分类不退化；实际 Java main 子进程处理，不用 Mock 代替隔离证明。
- 可控卡死子进程越过截止后确实退出；崩溃、非法输出、内存/输出/磁盘限制不影响随后正常文件；容量占满后明确拒绝并恢复。
- 临时目录、流、进程和并发许可在成功/失败/取消时释放；TenantContext 和 trace 在调用线程中保持原样，不通过环境传递敏感身份。
- 打包后的 Boot artifact 启动解析 main 验证通过；Compose 静态校验及本地隔离验证单独记录，未部署到生产。

## 验证结果与操作边界

- 完整回归 638 项，0 失败/错误、9 项外部依赖跳过；其中知识库 458 项、5 跳过。真实 fork 覆盖全部 17 个语料场景，以及卡死、崩溃、堆/输出/磁盘超限、输入读取失败、容量拒绝与关闭。
- 打包后的 Boot fat jar 真实启动解析 main；另在 Linux 临时容器中运行 PDF/DOCX/XLSX/CSV，使用非 root、只读根文件系统、禁网、3 GiB 内存、2 CPU、256 pids、512 MiB tmpfs，四类均通过且任务目录清空。容器已自动移除。
- 本轮四个样本单次冷启动解析耗时约 1.17～1.70 秒，整容器 `memory.peak=415653888` 字节；这不是并发压测、P95 或生产 SLA，也不能由此得出 fork 比进程内更快。
- HTTP 分类修正后补跑 `DocumentControllerTest,IngestionRecoveryTest`，10 项通过；进程崩溃返回 503，但任务不自动重试同一崩溃输入。完整回归与容器镜像早于这项仅 HTTP 分类的修改，专项日志分别保留，不冒充镜像包含最新 HTTP 代码。
- 原文 S3 连接/读取/整次调用默认超时 2 秒/30 秒/2 分钟；暂存 60 秒在读边界检查。任意 InputStream 的单次阻塞读取不具备强杀保证。
- `split` worker 已配置容器资源边界；其他部署必须显式配置等价限制。仅启动 Java 子进程不能隔离同用户的文件/网络访问，当前不是恶意代码安全沙箱。OCR 与递归嵌入附件默认关闭。
- 子进程启动不可用/容量满/源读取失败有限退避；时间/资源/页数/字节超限、崩溃或终止失败进入人工处置。终止无法确认时保留目录和并发额度，防止继续放大资源消耗。
- 旧目录 SPI 加载路径仍需统一接入；本项不把该路径、上传/embedding 全链路内存预算或租户公平调度宣称完成，继续由 KDP-06-B/05-B 处理。
