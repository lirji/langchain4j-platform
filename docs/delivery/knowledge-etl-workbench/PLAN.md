# 数据接入工作台与运行记录

授权：用户确认按推荐实现工作台和运行记录；延续正常任务分支、提交、合并推送main授权，不包含部署。

- S1 后端：增量迁移V8，来源暂停/恢复（独立控制版本）、受治理手动轮询/失败任务重试、同租户显式operator-user-ids授权；后台执行身份不变。
- S2 运行记录：一个运行对应一页增量数据，等待入库/失败/重试保持同一运行与快照，成功后进入历史。记录首次触发人、执行身份、开始/更新时间/完成时间、配置与游标摘要、逐条结果和新增/更新/删除/跳过/失败数量。分页有界，不公开原文、端点、凭据或原始游标。
- S3 前端：在现有RAG工作台增加“数据接入”分区，来源列表→详情→运行历史/失败记录→恢复；沿用WorkbenchSection、InfoNote、主题控件。身份切换取消请求并清空旧数据。真实接口没有来源时显示空态，关闭或旧后端显示未启用，不硬编码业务数据。
- S4 验证：服务端授权/CAS/暂停在途任务/崩溃恢复/统计幂等/分页、真实MySQL；前端权限/迟到响应/冲突恢复/受理与成功区分、类型/构建、实际浏览器检查。

范围：不在页面创建/编辑来源URL、凭据或字段映射，不新增连接器，不部署现有服务。暂停只阻止后续协调步骤，已经提交的入库任务可能完成；恢复使用原检查点和原任务，不清空或跳过失败记录。

运行状态：RUNNING→WAITING/BLOCKED/PAUSED→RUNNING→SUCCEEDED。SUCCEEDED为不可变终态；列表按数据库序号降序游标分页。暂停和恢复单独记录操作者审计；运行起始操作者不被后续调度覆盖。
